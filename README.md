# bot_green_gavan

Telegram-бот предзаказа еды для ЖК «Зелёная Гавань» (только самовывоз).

## Описание
Бот позволяет жильцам жилого комплекса заранее оформить заказ в заведениях («Пиццерия», «Varka», «Булочки») и забрать его ко времени без очередей.

### Ключевые возможности:
- **Только самовывоз:** у каждого заведения зафиксирована точка выдачи (`pickup_point`).
- **Заказ в несколько кликов:** без `@grammyjs/conversations`, корзина сохраняется в SQLite (`cart_items`).
- **Уведомления и статусы:** цепочка `sent` → `accepted` → `ready` → `issued` (побочные: `cancelled`, `expired`).
- **Атомарные переходы:** защита от повторных кликов (`UPDATE ... WHERE status = <ожидаемый>`).
- **Безопасность в группах заведений:** смена статусов доступна только сотрудникам из таблицы `place_staff`.
- **Автоматическая проверка просрочки:** неподтверждённые заказы автоматически переводятся в `expired` через фоновый таймер (раз в минуту).
- **152-ФЗ:** согласие при входе и команда `/delete_me` для удаления персональных данных.

## Стек технологий
- **Node.js** (ESM, `>=20.6`)
- **grammY**
- **better-sqlite3**

## Быстрый старт

1. Склонируйте репозиторий и установите зависимости:
   ```bash
   npm install
   ```

2. Создайте файл `.env` на основе `.env`:
   ```bash
   cp .env .env
   ```
   Укажите `BOT_TOKEN` и при необходимости `STAFF_TELEGRAM_ID`.

3. Наполните базу данных пилотными заведениями и меню:
   ```bash
   npm run seed
   ```

4. Запустите бота:
   ```bash
   npm run dev
   # или для продакшена:
   npm start
   ```
